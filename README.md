# DAYZ DROP

Магазин одежды в Telegram: бот + мини-приложение + админ-панель. Всё на бесплатных сервисах.

## Как устроено

```
Покупатель ──► Telegram-бот ──► Мини-апп (GitHub Pages, webapp/)
                    │                    │  запросы с подписью Telegram
                    ▼                    ▼
              Сервер бота + API (Render free, bot/)
                    │
                    ▼
              База Postgres (Neon free)
```

- `webapp/` — мини-апп: каталог, корзина, оформление, мои заказы, админка. Чистый HTML/JS, без сборки.
- `bot/` — Python (aiogram 3 + aiohttp + SQLAlchemy): бот, API для мини-аппа, логика заказов.
  - `texts.py` — **все тексты бота**, меняются без правки кода
  - `services.py` — заказы, остатки, ручная проверка оплаты, уведомления
  - `api.py` — API мини-аппа, `handlers.py` — команды и кнопки бота
- Фото товаров и чеки хранятся в самом Telegram (по `file_id`), отдельное хранилище не нужно.

## Оплата без ИП — ручная проверка

1. Покупатель оформляет заказ → товар резервируется (списывается со склада), статус **«Ожидает оплаты»**.
2. Бот присылает реквизиты (задаются в админке → Настройки) и просит указать в переводе `Заказ #N`.
3. Покупатель шлёт скриншот/PDF чека боту в чат или загружает в мини-аппе → статус **«Проверяем оплату»**.
4. Оба админа получают чек с кнопками **✅ Деньги пришли / ❌ Не пришли**.
   - ✅ → **«Оплачен»**, покупателю приходит подтверждение.
   - ❌ → обратно в «Ожидает оплаты», покупатель получает просьбу проверить перевод.
5. Админ вводит трек-номер → **«Отправлен»** (покупателю приходит трек) → **«Получен»**.
6. Отмена (покупателем до оплаты или админом в любой момент) возвращает товар на склад.

Покупатель не может подтвердить оплату сам: статус меняют только админы (`ADMIN_IDS`).
Все запросы мини-аппа проверяются по подписи Telegram, поэтому подделать пользователя нельзя.

## Деплой (бесплатно)

1. **Мини-апп** — GitHub Pages, публикуется сам через Actions при пуше в `main`.
2. **База** — [Neon](https://neon.tech): создать проект и скопировать строку подключения.
3. **Сервер** — [Render](https://render.com) → New → Blueprint → этот репозиторий.
   Ввести `BOT_TOKEN` и `DATABASE_URL`. Вебхук бот ставит сам.
4. В `webapp/config.js` указан адрес сервера на Render.

Бесплатный Render засыпает через 15 минут без запросов. Бот сам пингует себя каждые 10 минут, а если всё же уснёт — первый ответ придёт примерно через 30–60 секунд.

## Локальный запуск

```bash
cd bot
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
.venv\Scripts\python main.py
```
Без `DATABASE_URL` используется локальный SQLite, бот работает через polling.
